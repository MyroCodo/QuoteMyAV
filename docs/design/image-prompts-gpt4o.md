## Usage Notes for GPT-4o

1. **Generate one image at a time** for best results
2. **Request variations** if first output doesn't match brand
3. **Specify "no text" clearly** if you want text-free versions
4. **Ask for transparent backgrounds explicitly** - GPT-4o defaults to backgrounds
5. **Request specific dimensions** - GPT-4o may default to square
6. **Download and save** originals immediately before requesting edits
7. **Use consistent prompt structure** for visual cohesion across assets

---

## Post-Generation Checklist

After generating images, verify:
- [ ] Colors match brand tokens (use eyedropper tool)
- [ ] Images work on both dark (#0F172A) and light backgrounds
- [ ] Icons are readable at small sizes (test 32x32px)
- [ ] No unwanted text or artifacts
- [ ] Consistent style across all assets
- [ ] File sizes optimized for web (<500KB for PNGs)
- [ ] SVGs converted properly if needed
