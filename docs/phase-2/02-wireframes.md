# QuoteMyAV - Phase 2 Wireframes

## Overview

These wireframes cover Phase 2 features that build on the MVP:
- Upload Mode (Document Parsing)
- Chat Interface (Conversational Intake)
- Equipment Library (Pro)
- Custom Templates (Pro)
- Branding Settings (Pro)

Uses the same dark tech design system as MVP.
